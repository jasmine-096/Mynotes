# 心理修复：事实、逻辑与边界

> [!important] 这个文件的用途
> 不是给家人定罪，也不是证明“我坏掉了”。它是一个处理当下情绪与精神状态的调试系统：把模糊压抑编译成可观察数据，识别自动化预测，恢复判断权，并产生一个现实行动。

> [!warning] 核心规则
> 1. **当前状态优先**：不强迫回忆过去；先处理今天的情绪、身体、行为和环境。
> 2. **事实先于术语**：先写可观察数据，再判断是否属于某种认知偏差或话术。
> 3. **意图不能覆盖后果**：“为了你好”即使是真实动机，也不能自动证明手段合理。
> 4. **模型不是诊断**：本文件只记录假设与实验，不替代心理咨询或医疗评估。
> 5. **先稳定，再分析**：情绪强度很高时，先降载；不要在报警状态下审判自己或重写人生结论。

## 零、当前状态调试模型 v0.3

### 过去行为与健康替代行为对照表

> [!important] 使用方式
> “过去行为”只记录我已经观察并说出的模式，不是人格标签或医学诊断；“健康替代行为”也不是必须完美执行的命令。真正的改进，是旧路径启动后，我能更早发现，并多一次暂停、选择或返回现实的机会。

### 对照表的判定原则

1. **不以情绪是否消失判成败**：焦虑、遗憾或性欲仍存在，但行为选择权增加，也算改进。
2. **不以别人是否满意判成败**：拒绝后对方不高兴，不自动说明边界错误；聊天后对方没有兴趣，也不说明整体价值低。
3. **不以一次失败推翻模型**：只记录触发、行为和结果；出现重复模式后再调整。
4. **不删除过去行为日志**：历史数据用于比较，不用于羞辱自己。
5. **模型只读规则**：当天任务未完成时，改进念头只进入 Inbox；先执行当前协议，再在预定复盘时间判断是否更新。

### 最终目标：健康精神状态 v0.3

> [!important] 目标定义
> 健康不是永远开心、自信、无焦虑，也不是消灭遗憾、性欲和对他人认可的需要。目标是：情绪可以出现，但它不自动接管判断与行为；我能识别状态、保留选择权、回到现实任务，并在需要时主动求助。

以下指标由具体故障场景反推。它们是当前版本的验收标准，不是人格道德评分；后续只根据实际记录迭代。

#### 1. 任务受挫后的恢复力

```text
发现当天学习未达到规定时间
→ 不追缴已经损失的时间，不进行人格审判
→ 在30分钟内重新开始剩余任务
→ 复盘留到预定复盘时间，不在执行时重写计划
```

**验收证据**：从意识到焦虑，到重新开始原计划内任务所用的时间。

#### 2. 面对过去遗憾与未来灾难化预测

```text
“我错过了她/以后可能一直一个人”的念头出现
→ 不强行压制，也不继续和它争辩
→ 在状态日志中写一行
→ 回到念头出现前的原任务，连续执行10分钟
```

**验收证据**：日志中的一行记录，以及原任务连续执行10分钟。

#### 3. 保留人际边界与自主权

收到自己不想立刻接受的请求时：

> 我现在不能答应，等我完成手头任务后再回复你。

完成自己的任务后，如果仍然不想做，且拒绝不会危及人身、住宿或经济安全：

> 这件事我不打算做，你再问问别人吧。

**验收标准**：不因预测对方会不高兴而自动答应；允许自己延迟决定，也允许最终拒绝。若存在现实权力或安全风险，优先采用离开、减少信息披露或寻求支持，而不是机械套用拒绝句。

#### 4. 对成人视频与自慰保持选择权

```text
冲动出现
→ 先深呼吸并暂停10分钟
→ 分别检查：性欲 / 焦虑 / 疲劳或无聊（0—10）
→ 说清这次主要是在满足性欲，还是在逃避情绪
→ 再自主决定是否自慰
```

第一阶段不设“允许自慰”的分数阈值，也不以彻底禁止为目标。**验收的是能否暂停、识别和选择，而不是是否禁欲。**

#### 5. 不把局部社交结果写入全局人格

```text
这说明这次互动没有接上，或我的聊天技能当前不足；
但不说明我的整体价值低，也不说明未来不会改变；
下一步提出一个与当前场景有关的真实小问题。
```

问题围绕共同课程、当下天气、吃饭或正在发生的事情；目的不是表现自己或强迫续聊，而是完成一次真实、尊重的连接尝试。

#### 6. 总体验收条件

达到目标不等于上述行为每次都成功。当前定义为：

- 能更早识别“低落、焦虑、讨好、反刍、自动寻求刺激”正在启动；
- 多数时候能在自动行为前插入暂停；
- 失败后不做终身判决，能回到原任务或现实生活；
- 能把别人的情绪、一次聊天结果和自己的整体价值分开；
- 状态持续恶化或功能明显受损时，能主动使用专业支持，而不是独自硬扛。

> [!warning] 未定义项
> 当前还不知道“什么条件下选择自慰”以及“健康状态达到多少比例才算稳定”。先收集实际数据，不凭空设置规则。模型不得借此无限扩张成新的自我控制系统。

### 目标

不是强迫自己“永远积极”，而是逐步做到：

1. 识别情绪是由什么触发的；
2. 区分事实、预测与反事实想象；
3. 在自动反应前插入一个可控动作；
4. 用现实数据更新模型，而不是用一次低落给人生定论。

### 暂定回路（假设，不是诊断）

```text
白天独处/现实连接少
→ 注意力转向过去遗憾与未来关系
→ 反事实想象：“当时如果……就好了”
→ 灾难化预测：“以后不会有人喜欢我”
→ 低落、自卑、想退回宿舍
→ 新的社交数据更少
→ 原预测暂时没有被现实修正
```

其他待验证变量：睡眠质量、日间光照与活动量、学习压力、孤独感、色情/自慰前的情绪状态、与家人互动后的反应。**未记录前不把它们当作根因。**

### 四层处理架构

| 层级 | 调试问题 | 默认动作 |
|---|---|---|
| L0 安全 | 有没有自伤、无法保证安全、明显失控？ | 立即联系可信任的人、学校心理中心或医院；不独处硬扛 |
| L1 稳定 | 身体是否处于高唤醒/低能量？ | 离开屏幕，喝水、走动、呼吸、进食或休息；暂缓人生判断 |
| L2 认知 | 我写的是事实、预测，还是反事实？ | 分成“已知/未知/下一步可测试”三列 |
| L3 行动 | 今天能恢复哪一个最小权限？ | 一个可验证动作：离开宿舍、完成任务、延迟自动行为、正常交流 |

### 认知断言三分法

遇到“我以后一直会是一个人”这类句子，必须改写为：

- **已知事实**：我目前很少和女生聊天。
- **未知预测**：未来是否会遇到并建立关系。
- **当前行动**：在自然场景中进行一次低风险交流，观察真实结果。

不得把情绪强度当作事实概率。`我很害怕` 不等于 `事情一定会发生`。

不回忆高中，只记录最近一次或当天一次。连续记录 3—7 天后再找模式。

### 自动行为拦截器

当准备立即答应别人、反复回放遗憾、靠自慰/刷手机逃避或开始自我羞辱时，先执行：

```text
暂停 10—15 分钟
→ 写下触发与自动句子
→ 选择一个低成本动作
→ 再决定是否执行原行为
```

这不是禁止行为，而是把“自动执行”改成“有记录的选择”。

### 何时升级到专业支持

若低落多数天持续两周以上，或明显影响睡眠、食欲、学习、社交、兴趣，预约学校心理中心或正规医院心理科/精神科评估。若出现自伤念头、具体计划或无法保证安全，立即联系身边可信任的人并前往急诊/拨打当地急救电话；不要独自进行逻辑分析。

### 可能的话术模型（判断后再勾选）

- [ ] **莫特—贝利**：先提出强而难辩护的主张；受质疑时退回弱而安全的主张；压力消失后再恢复强主张。
- [ ] **诉诸动机**：用“我是好心”替代对行为是否合理、后果是否有害的论证。
- [ ] **虚假两难**：把选项压成“听话”或“不孝/失败”，抹掉其他方案。
- [ ] **移动球门**：我满足一个条件后，又临时增加新条件。
- [ ] **否定感受或事实**：不回应具体事件，只宣布“你想多了”。
- [ ] **尚不能判断**：证据不足，先记录，不急着贴标签。
